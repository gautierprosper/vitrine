Entrar no PlannInTime
  • ✅ Telefone / email + senha.

  • ✅ Esqueceu a senha? Você recebe um link.
  • ✅ Formato: +237 6XX XX XX XX.

🏠 2. Início - HomeScreen

Os seus grupos num relance
  • ✅ O seu nome + última conexão.
  • ✅ Cartão = 1 grupo: nome, datas, % Consumido (vermelho) vs % Realizado (verde).
  • ✅ Chips: Concluídas / Atrasadas / Em curso / Não começadas.
  • ✅ Botão + verde: Criar um grupo.
  • ✅ Menu ⋮ : Perfil, Foto, Senha, Arquivos, Sobre.
  • ✅ Botão ? verde: Guia + Sobre.
💡 Clique num cartão para entrar no grupo.
🌐 Ver no site →

👥 3. Criar um grupo

A partir da HomeScreen
  • ✅ Botão + → Nome do grupo.
  • ✅ Opcional: Data de início + Data de vencimento (início < fim).
  • ✅ Membros: Diretório ou Manual.
  • ✅ Sem app = convite SMS / WhatsApp.
💡 Só o admin pode adicionar / remover membros.
🌐 Ver no site →

📋 4. Lista de tarefas

O coração do PlannInTime
  • ✅ Linha = 1 tarefa: título, vencimento, responsável, estado.
  • ✅ Laranja = A fazer, Azul = Em curso, Verde = Concluída, Vermelho = Atrasada.
  • ✅ Tarefa riscada = concluída.
  • ✅ Clique para detalhe + subtarefas.
  • ✅ Filtro: Minhas tarefas / Atrasadas / Por responsável.
💡 Use o filtro quando tiver +20 tarefas.
🌐 Ver no site →

✅ 5. Detalhe de uma tarefa

Subtarefas e estado
  • ✅ Descrição, datas, responsáveis.
  • ✅ Marque as subtarefas, o % avança sozinho.
  • ✅ Estado: A fazer → Em curso → Concluída.
  • ✅ Só o admin ou o responsável pode modificar.
💡 Nunca coloque Concluída se uma subtarefa ainda está por fazer.
🌐 Ver no site →

💬 6. Fórum do grupo

Como WhatsApp, mas dentro do grupo
  • ✅ Em baixo: escreva + Enviar. Botão cinza se vazio.
  • ✅ Responder: seta ▼ → Responder.
  • ✅ Copiar: seta ▼ → Copiar.
  • ✅ Editar: seta ▼ → Editar (as suas mensagens). Aparece a palavra Editado.
  • ✅ Apagar: seta ▼ → Apagar (as suas mensagens).
  • ✅ Info: seta ▼ → Info. Quem leu / não leu + hora.
  • ✅ ✓✓ cinza = não lido por todos, ✓✓ azul = todos leram.
  • ✅ Primeiro não lido: o app coloca-o diretamente nele.
💡 Pergunte « Quem está disponível? » e veja os ✓✓ azuis.
🌐 Ver no site →

⚙️ 7. Configurações do grupo

Ajustar tudo no mesmo lugar
  • ✅ TaskListPage → ⚙️ Configurações.
  • ✅ Renomear, Filtrar, Evolução, Notificações, Gráficos, Exportar, Guia.
  • ✅ Só o admin vê Renomear / Notificações.
💡 Se não é admin, vai ver menos botões, é normal.
🌐 Ver no site →

✏️ 8. Renomear o grupo

Nome + datas
  • ✅ Configurações → Renomear o grupo.
  • ✅ Mude o nome.
  • ✅ Definir data de início / Data de vencimento.
  • ✅ Regra: início ANTES do vencimento, senão mensagem vermelha.
💡 A data de vencimento controla o % Consumido.
🌐 Ver no site →

📈 9. Evolução das tarefas

Consumido / Realizado
  • ✅ Por vencimento: % sobre tempo decorrido.
  • ✅ Por total: subtarefas feitas / total.
  • ✅ Exemplo: 10 subtarefas, 7 feitas = 70% Realizado.
💡 Se Realizado < Consumido = está atrasado.
🌐 Ver no site →

🔔 10. Notificações

Lembretes 7h e 9h
  • ✅ Configurações → Notificações do grupo.
  • ✅ Modelos: Todos, Admins, Responsáveis, Responsáveis atrasados.
  • ✅ Novo modelo → marque os membros.
  • ✅ 7h = tarefas atrasadas, 9h = vencimentos.
💡 Verifique as notificações nas configurações do telefone.
🌐 Ver no site →

📊 11. Gráficos

Azul vs Verde / Vermelho
  • ✅ Responsável: Todos ou 1 pessoa.
  • ✅ Azul = Previsto, Verde = Feito a tempo, Vermelho = Atrasado, Laranja = Em curso.
💡 Perfeito para a reunião: « Veja onde está o Jean »
🌐 Ver no site →

📤 12. Exportar

Semanal ou Geral — Sem PDF, direto em HTML
  • ✅ Configurações → Exportar.
  • ✅ Semanal: 6 dias (Seg-Sáb), Geral: todo o período.
  • ✅ Marque: Com subtarefas, Com responsáveis.
  • ✅ Pré-visualização → Partilhar / Imprimir.
  • ✅ Formato auto: A4 se pequeno, A3 paisagem se +90 dias.
💡 Em reunião, exporte Semanal. Para o cliente, Geral.
🌐 Ver no site →

🗄️ 13. Arquivar, sair, denunciar

Ações sensíveis
  • ✅ Arquivar: desaparece do início, guardado 365 dias.
  • ✅ Restaurar: Arquivos → Pressão longa 5s → Restaurar.
  • ✅ Sair: sai do grupo.
  • ✅ Denunciar: admin / super-admin alertado.
  • ✅ Apagar definitivamente: irreversível.
💡 Use Apagar só se tiver a certeza.
