🔑 1. Connexion - LoginScreen

Entrer dans PlannInTime
  • ✅ Téléphone / email + mot de passe.
  • ✅ Pas de compte ? Créer un compte.
  • ✅ Mot de passe oublié ? Tu reçois un lien.
  • ✅ Format : +237 6XX XX XX XX.
💡 Reste connecté, l'app mémorise ta session.
🌐 Voir sur le site →

🏠 2. Accueil - HomeScreen

Tes groupes en un coup d'oeil
  • ✅ Ton nom + dernière connexion.
  • ✅ Carte = 1 groupe : nom, dates, % Consommé (rouge) vs % Réalisé (vert).
  • ✅ Chips : Terminées / En retard / En cours / Non commencées.
  • ✅ Bouton + vert : Créer un groupe.
  • ✅ Menu ⋮ : Profil, Photo, Mot de passe, Archives, À propos.
  • ✅ Bouton ? vert : Guide + À propos.
💡 Clique sur une carte pour entrer dans le groupe.
🌐 Voir sur le site →

👥 3. Créer un groupe

Depuis HomeScreen
  • ✅ Bouton + → Nom du groupe.
  • ✅ Optionnel : Date de début + Date d'échéance (début < fin).
  • ✅ Membres : Répertoire ou Manuel.
  • ✅ Sans app = invitation SMS / WhatsApp.
💡 Seul l'admin peut ajouter / supprimer des membres.
🌐 Voir sur le site →

📋 4. Liste des tâches

Le coeur de PlannInTime
  • ✅ Ligne = 1 tâche : titre, échéance, responsable, statut.
  • ✅ Orange = À faire, Bleu = En cours, Vert = Terminé, Rouge = En retard.
  • ✅ Tâche barrée = terminée.
  • ✅ Clique pour détail + sous-tâches.
  • ✅ Filtre : Mes tâches / En retard / Par responsable.
💡 Utilise le filtre quand tu as +20 tâches.
🌐 Voir sur le site →

✅ 5. Détail d'une tâche

Sous-tâches et statut
  • ✅ Description, dates, responsables.
  • ✅ Coche les sous-tâches, le % avance tout seul.
  • ✅ Statut : À faire → En cours → Terminé.
  • ✅ Seul admin ou responsable peut modifier.
💡 Ne mets jamais Terminé si une sous-tâche est encore à faire.
🌐 Voir sur le site →

💬 6. Forum du groupe

Comme WhatsApp, mais dans le groupe
  • ✅ En bas : écris + Envoyer. Bouton gris si vide.
  • ✅ Répondre : flèche ▼ → Répondre.
  • ✅ Copier : flèche ▼ → Copier.
  • ✅ Modifier : flèche ▼ → Modifier (tes messages). Mot Modifié apparaît.
  • ✅ Supprimer : flèche ▼ → Supprimer (tes messages).
  • ✅ Infos : flèche ▼ → Infos. Qui a lu / pas lu + heure.
  • ✅ ✓✓ gris = pas lu par tous, ✓✓ bleu = tout le monde a lu.
  • ✅ Premier non lu : l'app te met direct dessus.
💡 Demande « Qui est dispo ? » et regarde les ✓✓ bleus.
🌐 Voir sur le site →

⚙️ 7. Paramètres du groupe

Tout régler au même endroit
  • ✅ TaskListPage → ⚙️ Paramètres.
  • ✅ Renommer, Filtrer, Évolution, Notifications, Graphiques, Export, Guide.
  • ✅ Seul l'admin voit Renommer / Notifications.
💡 Si tu n'es pas admin, tu verras moins de boutons, c'est normal.
🌐 Voir sur le site →

✏️ 8. Renommer le groupe

Nom + dates
  • ✅ Paramètres → Renommer le groupe.
  • ✅ Change le nom.
  • ✅ Définir date de début / Date d'échéance.
  • ✅ Règle : début AVANT échéance, sinon message rouge.
💡 La date d'échéance pilote le % Consommé.
🌐 Voir sur le site →

📈 9. Évolution des tâches

Consommé / Réalisé
  • ✅ Par échéance : % sur temps écoulé.
  • ✅ Par total : sous-tâches faites / total.
  • ✅ Exemple : 10 sous-tâches, 7 faites = 70% Réalisé.
💡 Si Réalisé < Consommé = tu es en retard.
🌐 Voir sur le site →

🔔 10. Notifications

Rappels 7h et 9h
  • ✅ Paramètres → Notifications du groupe.
  • ✅ Modèles : Tous, Admins, Responsables, Responsables en retard.
  • ✅ Nouveau modèle → coche les membres.
  • ✅ 7h = tâches en retard, 9h = échéances.
💡 Vérifie les notifications dans les réglages du téléphone.
🌐 Voir sur le site →

📊 11. Graphiques

Bleu vs Vert / Rouge
  • ✅ Responsable : Tous ou 1 personne.
  • ✅ Bleu = Prévu, Vert = Fait à l'heure, Rouge = En retard, Orange = En cours.
💡 Parfait pour la réunion : « Voilà où en est Jean »
🌐 Voir sur le site →

📤 12. Exporter

Hebdo ou Général — Sans PDF, direct en HTML
  • ✅ Paramètres → Exporter.
  • ✅ Hebdo : 6 jours (Lun-Sam), Général : toute la période.
  • ✅ Coche : Avec sous-tâches, Avec responsables.
  • ✅ Aperçu → Partager / Imprimer.
  • ✅ Format auto : A4 si petit, A3 paysage si +90 jours.
💡 En réunion, exporte en Hebdo. Pour le client, en Général.
🌐 Voir sur le site →

🗄️ 13. Archiver, quitter, signaler

Les actions sensibles
  • ✅ Archiver : disparaît de l'accueil, gardé 365 jours.
  • ✅ Restaurer : Archives → Appui long 5s → Restaurer.
  • ✅ Quitter : tu sors du groupe.
  • ✅ Signaler : admin / super-admin alerté.
  • ✅ Supprimer définitivement : irréversible.
💡 N'utilise Supprimer que si tu es sûr.
🌐 Voir sur le site →

💡 14. Cas pratiques

Ce que tout le monde demande
  • ✅ En retard : Filtre → Mes tâches → En retard.
  • ✅ Réunion lundi : Paramètres → Export → Hebdo → Partager.
  • ✅ Voir Jean : Graphiques → Responsable = Jean → Exporter.
💡 En 2 minutes, ton rapport est prêt.
