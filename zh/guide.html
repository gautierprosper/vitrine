🔑 1. 登录 - LoginScreen

进入 PlannInTime
  • ✅ 电话 / 邮箱 + 密码。
  • ✅ 没有账号？创建账号。
  • ✅ 忘记密码？您会收到一个链接。
  • ✅ 格式：+237 6XX XX XX XX。
💡 保持登录，应用会记住您的会话。
🌐 在网站上查看 →

🏠 2. 首页 - HomeScreen

一眼看清您的群组
  • ✅ 您的名字 + 上次登录。
  • ✅ 卡片 = 1 个群组：名称、日期、% 已消耗（红色） vs % 已完成（绿色）。
  • ✅ 标签：已完成 / 逾期 / 进行中 / 未开始。
  • ✅ 绿色 + 按钮：创建群组。
  • ✅ 菜单 ⋮ ：个人资料、照片、密码、存档、关于。
  • ✅ 绿色 ? 按钮：指南 + 关于。
💡 点击卡片进入群组。
🌐 在网站上查看 →

👥 3. 创建群组

从 HomeScreen
  • ✅ + 按钮 → 群组名称。
  • ✅ 可选：开始日期 + 截止日期（开始 < 结束）。
  • ✅ 成员：通讯录 或 手动。
  • ✅ 无应用 = SMS / WhatsApp 邀请。
💡 只有管理员可以添加 / 删除成员。
🌐 在网站上查看 →

📋 4. 任务列表

PlannInTime 的核心
  • ✅ 行 = 1 个任务：标题、截止日期、负责人、状态。
  • ✅ 橙色 = 待办，蓝色 = 进行中，绿色 = 已完成，红色 = 逾期。
  • ✅ 划掉的任务 = 已完成。
  • ✅ 点击查看详情 + 子任务。
  • ✅ 筛选：我的任务 / 逾期 / 按负责人。
💡 当您有 +20 个任务时请使用筛选。
🌐 在网站上查看 →

✅ 5. 任务详情

子任务和状态
  • ✅ 描述、日期、负责人。
  • ✅ 勾选子任务，% 会自动前进。
  • ✅ 状态：待办 → 进行中 → 已完成。
  • ✅ 只有管理员或负责人可以修改。
💡 如果还有子任务未做，千万不要标为已完成。
🌐 在网站上查看 →

💬 6. 群组论坛

像 WhatsApp，但 在群组里
  • ✅ 底部：写 + 发送。为空时按钮为灰色。
  • ✅ 回复：箭头 ▼ → 回复。
  • ✅ 复制：箭头 ▼ → 复制。
  • ✅ 编辑：箭头 ▼ → 编辑（您的消息）。会出现“已编辑”字样。
  • ✅ 删除：箭头 ▼ → 删除（您的消息）。
  • ✅ 信息：箭头 ▼ → 信息。谁已读 / 未读 + 时间。
  • ✅ ✓✓ 灰色 = 不是所有人都读了，✓✓ 蓝色 = 所有人都读了。
  • ✅ 第一条未读：应用会直接带您到那里。
💡 问“谁有空？”然后看蓝色的 ✓✓。
🌐 在网站上查看 →

⚙️ 7. 群组设置

所有设置都在一个地方
  • ✅ TaskListPage → ⚙️ 设置。
  • ✅ 重命名、筛选、进展、通知、图表、导出、指南。
  • ✅ 只有管理员能看到 重命名 / 通知。
💡 如果您不是管理员，您会看到更少的按钮，这是正常的。
🌐 在网站上查看 →

✏️ 8. 重命名群组

名称 + 日期
  • ✅ 设置 → 重命名群组。
  • ✅ 更改名称。
  • ✅ 设置开始日期 / 截止日期。
  • ✅ 规则：开始 必须在 截止 之前，否则红色提示。
💡 截止日期决定 % 已消耗。
🌐 在网站上查看 →

📈 9. 任务进展

已消耗 / 已完成
  • ✅ 按截止日期：% 按已过时间。
  • ✅ 按总数：已完成子任务 / 总数。
  • ✅ 例子：10 个子任务，7 个完成 = 70% 已完成。
💡 如果 已完成 < 已消耗 = 您落后了。
🌐 在网站上查看 →

🔔 10. 通知

7h 和 9h 提醒
  • ✅ 设置 → 群组通知。
  • ✅ 模板：所有人、管理员、负责人、逾期负责人。
  • ✅ 新模板 → 勾选成员。
  • ✅ 7h = 逾期任务，9h = 截止日期。
💡 请在手机设置中检查通知。
🌐 在网站上查看 →

📊 11. 图表

蓝色 vs 绿色 / 红色
  • ✅ 负责人：所有人 或 1 个人。
  • ✅ 蓝色 = 计划，绿色 = 按时完成，红色 = 逾期，橙色 = 进行中。
💡 会议完美用法：“看看 Jean 进展到哪里了”
🌐 在网站上查看 →

📤 12. 导出

每周 或 全部 — 不用 PDF，直接 HTML
  • ✅ 设置 → 导出。
  • ✅ 每周：6 天（周一-周六），全部：整个期间。
  • ✅ 勾选：带子任务，带负责人。
  • ✅ 预览 → 分享 / 打印。
  • ✅ 自动格式：小则 A4，+90 天则 A3 横向。
💡 开会时，导出每周版。给客户时，导出全部版。
🌐 在网站上查看 →

🗄️ 13. 存档、退出、举报

敏感操作
  • ✅ 存档：从首页消失，保留 365 天。
  • ✅ 恢复：存档 → 长按 5s → 恢复。
  • ✅ 退出：您退出群组。
  • ✅ 举报：管理员 / 超级管理员会收到提醒。
  • ✅ 永久删除：不可逆。
💡 只有在确定时才使用删除。
🌐 在网站上查看 →

💡 14. 实际案例

大家都问什么
  • ✅ 逾期：筛选 → 我的任务 → 逾期。
  • ✅ 周一会议：设置 → 导出 → 每周 → 分享。
  • ✅ 看 Jean：图表 → 负责人 = Jean → 导出。
💡 2 分钟，您的报告就准备好了。
