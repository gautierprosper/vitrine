🔑 1. Login - LoginScreen

Enter PlannInTime
  • ✅ Phone / email + password.
  • ✅ No account? Create an account.
  • ✅ Forgot password? You receive a link.
  • ✅ Format: +237 6XX XX XX XX.
💡 Stay logged in, the app remembers your session.

🏠 2. Home - HomeScreen

Your groups at a glance
  • ✅ Your name + last login.
  • ✅ Card = 1 group: name, dates, % Consumed (red) vs % Done (green).
  • ✅ Chips: Done / Late / In progress / Not started.
  • ✅ Green + button: Create a group.
  • ✅ ⋮ Menu: Profile, Photo, Password, Archives, About.
  • ✅ Green ? button: Guide + About.
💡 Click a card to enter the group.
🌐 View on site →

👥 3. Create a group

From HomeScreen
  • ✅ + button → Group name.
  • ✅ Optional: Start date + Due date (start < end).
  • ✅ Members: Directory or Manual.
  • ✅ Without app = SMS / WhatsApp invitation.
💡 Only admin can add / remove members.
🌐 View on site →

📋 4. Task List

The heart of PlannInTime
  • ✅ Line = 1 task: title, due date, owner, status.
  • ✅ Orange = To do, Blue = In progress, Green = Done, Red = Late.
  • ✅ Strikethrough task = done.
  • ✅ Click for detail + subtasks.
  • ✅ Filter: My tasks / Late / By owner.
💡 Use filter when you have +20 tasks.
🌐 View on site →

✅ 5. Task Detail

Subtasks and status
  • ✅ Description, dates, owners.
  • ✅ Check subtasks, % moves by itself.
  • ✅ Status: To do → In progress → Done.
  • ✅ Only admin or owner can edit.
💡 Never set Done if a subtask is still to do.
🌐 View on site →

💬 6. Group Forum

Like WhatsApp, but inside the group
  • ✅ Bottom: write + Send. Button grey if empty.
  • ✅ Reply: ▼ arrow → Reply.
  • ✅ Copy: ▼ arrow → Copy.
  • ✅ Edit: ▼ arrow → Edit (your messages). Edited word appears.
  • ✅ Delete: ▼ arrow → Delete (your messages).
  • ✅ Info: ▼ arrow → Info. Who read / not read + time.
  • ✅ ✓✓ grey = not read by all, ✓✓ blue = everyone read.
  • ✅ First unread: app puts you directly on it.
💡 Ask “Who is available?” and watch the blue ✓✓.
🌐 View on site →

⚙️ 7. Group Settings

Set everything in one place
  • ✅ TaskListPage → ⚙️ Settings.
  • ✅ Rename, Filter, Evolution, Notifications, Charts, Export, Guide.
  • ✅ Only admin sees Rename / Notifications.
💡 If you are not admin, you will see fewer buttons, that's normal.
🌐 View on site →

✏️ 8. Rename Group

Name + dates
  • ✅ Settings → Rename group.
  • ✅ Change name.
  • ✅ Set start date / Due date.
  • ✅ Rule: start BEFORE due, else red message.
💡 Due date drives % Consumed.
🌐 View on site →

📈 9. Task Evolution

Consumed / Done
  • ✅ By due date: % on elapsed time.
  • ✅ By total: subtasks done / total.
  • ✅ Example: 10 subtasks, 7 done = 70% Done.
💡 If Done < Consumed = you are late.
🌐 View on site →

🔔 10. Notifications

Reminders 7h and 9h
  • ✅ Settings → Group notifications.
  • ✅ Templates: All, Admins, Owners, Late owners.
  • ✅ New template → check members.
  • ✅ 7h = late tasks, 9h = due dates.
💡 Check notifications in phone settings.
🌐 View on site →

📊 11. Charts

Blue vs Green / Red
  • ✅ Owner: All or 1 person.
  • ✅ Blue = Planned, Green = Done on time, Red = Late, Orange = In progress.
💡 Perfect for meeting: “Here is where Jean is”
🌐 View on site →

📤 12. Export

Weekly or General — No PDF, direct HTML
  • ✅ Settings → Export.
  • ✅ Weekly: 6 days (Mon-Sat), General: whole period.
  • ✅ Check: With subtasks, With owners.
  • ✅ Preview → Share / Print.
  • ✅ Auto format: A4 if small, A3 landscape if +90 days.
💡 In meeting, export Weekly. For client, export General.
🌐 View on site →

🗄️ 13. Archive, Leave, Report

Sensitive actions
  • ✅ Archive: disappears from home, kept 365 days.
  • ✅ Restore: Archives → Long press 5s → Restore.
  • ✅ Leave: you exit the group.
  • ✅ Report: admin / super-admin alerted.
  • ✅ Delete permanently: irreversible.
💡 Use Delete only if you are sure.
🌐 View on site →

💡 14. Practical Cases

What everyone asks
  • ✅ Late: Filter → My tasks → Late.
  • ✅ Monday meeting: Settings → Export → Weekly → Share.
  • ✅ See Jean: Charts → Owner = Jean → Export.
💡 In 2 minutes, your report is ready.
