🔑 1. Anmeldung - LoginScreen

In PlannInTime einsteigen
  • ✅ Telefon / E-Mail + Passwort.
  • ✅ Kein Konto? Konto erstellen.
  • ✅ Passwort vergessen? Du erhältst einen Link.
  • ✅ Format: +237 6XX XX XX XX.
💡 Bleib angemeldet, die App merkt sich deine Sitzung.
🌐 Auf der Website ansehen →

🏠 2. Start - HomeScreen

Deine Gruppen auf einen Blick
  • ✅ Dein Name + letzter Login.
  • ✅ Karte = 1 Gruppe: Name, Daten, % Verbraucht (rot) vs % Erledigt (grün).
  • ✅ Chips: Erledigt / Verspätet / Laufend / Nicht begonnen.
  • ✅ Grüner + Button: Gruppe erstellen.
  • ✅ Menü ⋮ : Profil, Foto, Passwort, Archiv, Über uns.
  • ✅ Grüner ? Button: Anleitung + Über uns.
💡 Klicke auf eine Karte, um in die Gruppe zu gehen.
🌐 Auf der Website ansehen →

👥 3. Gruppe erstellen

Von HomeScreen
  • ✅ + Button → Gruppenname.
  • ✅ Optional: Startdatum + Fälligkeitsdatum (Start < Ende).
  • ✅ Mitglieder: Verzeichnis oder Manuell.
  • ✅ Ohne App = SMS / WhatsApp Einladung.
💡 Nur Admin kann Mitglieder hinzufügen / entfernen.
🌐 Auf der Website ansehen →

📋 4. Aufgabenliste

Das Herz von PlannInTime
  • ✅ Zeile = 1 Aufgabe: Titel, Fälligkeit, Verantwortlicher, Status.
  • ✅ Orange = Zu tun, Blau = Laufend, Grün = Erledigt, Rot = Verspätet.
  • ✅ Durchgestrichene Aufgabe = erledigt.
  • ✅ Klick für Detail + Unteraufgaben.
  • ✅ Filter: Meine Aufgaben / Verspätet / Nach Verantwortlichem.
💡 Nutze den Filter, wenn du +20 Aufgaben hast.
🌐 Auf der Website ansehen →

✅ 5. Aufgabendetail

Unteraufgaben und Status
  • ✅ Beschreibung, Daten, Verantwortliche.
  • ✅ Hake Unteraufgaben ab, % läuft von allein.
  • ✅ Status: Zu tun → Laufend → Erledigt.
  • ✅ Nur Admin oder Verantwortlicher kann ändern.
💡 Nie Erledigt setzen, wenn eine Unteraufgabe noch offen ist.
🌐 Auf der Website ansehen →

💬 6. Gruppen-Forum

Wie WhatsApp, aber in der Gruppe
  • ✅ Unten: schreiben + Senden. Button grau wenn leer.
  • ✅ Antworten: Pfeil ▼ → Antworten.
  • ✅ Kopieren: Pfeil ▼ → Kopieren.
  • ✅ Bearbeiten: Pfeil ▼ → Bearbeiten (deine Nachrichten). Wort Bearbeitet erscheint.
  • ✅ Löschen: Pfeil ▼ → Löschen (deine Nachrichten).
  • ✅ Infos: Pfeil ▼ → Infos. Wer gelesen / nicht gelesen + Uhrzeit.
  • ✅ ✓✓ grau = nicht von allen gelesen, ✓✓ blau = alle haben gelesen.
  • ✅ Erste ungelesene: App setzt dich direkt darauf.
💡 Frag « Wer ist verfügbar? » und schau auf die blauen ✓✓.
🌐 Auf der Website ansehen →

⚙️ 7. Gruppen-Einstellungen

Alles an einem Ort einstellen
  • ✅ TaskListPage → ⚙️ Einstellungen.
  • ✅ Umbenennen, Filtern, Entwicklung, Benachrichtigungen, Diagramme, Export, Anleitung.
  • ✅ Nur Admin sieht Umbenennen / Benachrichtigungen.
💡 Wenn du nicht Admin bist, siehst du weniger Buttons, das ist normal.
🌐 Auf der Website ansehen →

✏️ 8. Gruppe umbenennen

Name + Daten
  • ✅ Einstellungen → Gruppe umbenennen.
  • ✅ Name ändern.
  • ✅ Startdatum / Fälligkeitsdatum festlegen.
  • ✅ Regel: Start VOR Fälligkeit, sonst rote Meldung.
💡 Fälligkeitsdatum steuert % Verbraucht.
🌐 Auf der Website ansehen →

📈 9. Aufgaben-Entwicklung

Verbraucht / Erledigt
  • ✅ Nach Fälligkeit: % auf verstrichene Zeit.
  • ✅ Nach Gesamt: Unteraufgaben erledigt / gesamt.
  • ✅ Beispiel: 10 Unteraufgaben, 7 erledigt = 70% Erledigt.
💡 Wenn Erledigt < Verbraucht = du bist im Rückstand.
🌐 Auf der Website ansehen →

🔔 10. Benachrichtigungen

Erinnerungen 7h und 9h
  • ✅ Einstellungen → Gruppen-Benachrichtigungen.
  • ✅ Vorlagen: Alle, Admins, Verantwortliche, Verspätete Verantwortliche.
  • ✅ Neue Vorlage → Mitglieder anhaken.
  • ✅ 7h = verspätete Aufgaben, 9h = Fälligkeiten.
💡 Prüfe Benachrichtigungen in den Telefon-Einstellungen.
🌐 Auf der Website ansehen →

📊 11. Diagramme

Blau vs Grün / Rot
  • ✅ Verantwortlicher: Alle oder 1 Person.
  • ✅ Blau = Geplant, Grün = Pünktlich erledigt, Rot = Verspätet, Orange = Laufend.
💡 Perfekt fürs Meeting: « So steht Jean »
🌐 Auf der Website ansehen →

📤 12. Exportieren

Wöchentlich oder Allgemein — Kein PDF, direkt HTML
  • ✅ Einstellungen → Exportieren.
  • ✅ Wöchentlich: 6 Tage (Mo-Sa), Allgemein: ganze Periode.
  • ✅ Anhaken: Mit Unteraufgaben, Mit Verantwortlichen.
  • ✅ Vorschau → Teilen / Drucken.
  • ✅ Auto-Format: A4 wenn klein, A3 quer wenn +90 Tage.
💡 Im Meeting, wöchentlich exportieren. Für den Kunden, allgemein.
🌐 Auf der Website ansehen →

🗄️ 13. Archivieren, verlassen, melden

Sensible Aktionen
  • ✅ Archivieren: verschwindet von Start, 365 Tage behalten.
  • ✅ Wiederherstellen: Archiv → Lange drücken 5s → Wiederherstellen.
  • ✅ Verlassen: du verlässt die Gruppe.
  • ✅ Melden: Admin / Super-Admin benachrichtigt.
  • ✅ Endgültig löschen: unwiderruflich.
💡 Löschen nur nutzen, wenn du sicher bist.
🌐 Auf der Website ansehen →

💡 14. Praxis-Fälle

Was alle fragen
  • ✅ Verspätet: Filter → Meine Aufgaben → Verspätet.
  • ✅ Montag-Meeting: Einstellungen → Export → Wöchentlich → Teilen.
  • ✅ Jean sehen: Diagramme → Verantwortlicher = Jean → Exportieren.
💡 In 2 Minuten ist dein Bericht fertig.
